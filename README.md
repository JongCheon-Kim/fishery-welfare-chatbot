# ⚓ 경상남도 어촌복지 및 구인구직 원스톱 AI 도우미 (v1.0)
# fishery-welfare-chatbot
 경상남도 수산업·어촌기본계획 수립을 위한 어촌주민 복지 증진 정책사업 및 맞춤형 수산 구인구직 AI 챗봇 시범 모형입니다.

## 💡 주요 기능
1. **어촌 고령자/디지털 약자 맞춤 UI**: 대형 글씨, 고대비 모드, 스마트폰 카카오톡 스타일 반응형 디자인
2. **어촌 특화 복지 자격 진단**: 여성어업인, 고령자, 임산부, 장애인, 도서지역 주민 대상 맞춤 정책 매칭
3. **수산 구인구직 센터**: 어선, 양식장, 가공업 등 수산 일자리 매칭 및 어업 대체인력(쉼드림 수당) 연계
4. **품목/정책 선택형 스마트 콤보박스**: 검색창 호버/클릭 시 전체 복지·일자리 항목 직관적 선택 지원
5. **멀티모달 AI 연동**: 마이크 음성 대화(STT/TTS), 카메라/갤러리 서류 및 부상 사진 스캔(OCR)
6. **가변형 API 연동 구조**: Google Gemini API 및 공공데이터 포털 API 연동 옵션 제공

## 📁 파일 구조
- `index.html`: UI, 스타일, 정책 DB 및 자바스크립트 룰 엔진 통합 단일 파일
